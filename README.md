# CodexAutoTime — Windows releases

This repository is reserved for public binary releases of CodexAutoTime.

## Downloads

Published Windows builds will appear on the [Releases page](https://github.com/940963818qieke-crypto/CodexAutoTime-Releases/releases).

The application is a Windows GUI utility for selecting a local Codex session and scheduling messages with Windows Task Scheduler. It requires Windows and a working Codex CLI installation.

## Status

No verified EXE has been published yet. Do not treat a source ZIP or workflow definition as a ready-to-run executable. Each release will include the GUI executable and the runtime files it depends on, plus installation notes and checksums where available.
